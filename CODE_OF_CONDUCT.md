# Code of conduct

We are committed to a respectful, harassment-free project for everyone.
Contributors should communicate constructively, assume good faith while still
reviewing security claims rigorously, respect privacy and redistribution
rights, and avoid personal attacks or discriminatory conduct.

Maintainers may edit or remove contributions and temporarily or permanently
restrict participation for behavior that threatens people or the project.
Report conduct concerns privately to the maintainer who provided repository
access; a dedicated private contact will be published with the remote.
